# Endora Commerce 总体功能介绍（偏业务）

> 面向：业务、产品、运营与交付干系人  
> 目的：用业务语言说明「这套线上系统能做什么、给谁用、覆盖哪些核心场景」  
> 说明：本文描述 **Endora Commerce 开源电商平台** 的能力全景；部署实例若额外开启竞价等业务扩展模块，会在末节单独注明。

---

## 1. 一句话定位

**Endora Commerce** 是一套同时服务 **B2B（企业采购）** 与 **B2C（个人购买）** 的开源电商平台：同一套系统里既可「直接下单购买」，也可走「询价报价（RFQ）」；客户按 **组织（公司）** 管理，支持多账号角色、信用额度结算；运营侧有权限化后台，对外提供 API / Webhook，便于对接 ERP、PIM、WMS、CRM 等系统。

---

## 2. 三类使用者

| 角色 | 主要入口 | 典型诉求 |
| --- | --- | --- |
| 买家 / 采购方 | 商城前台（Storefront） | 查商品、比价、加购、询价、下单、查订单与发票、管理组织成员与地址 |
| 运营 / 销售 / 财务 / 售后 | 管理后台（Admin） | 管目录与价格、处理询价与订单、发货退货、促销内容、客户与信用额度、权限与审计 |
| 系统 / 集成 | API + Webhook + 连接器抽象 | 与外部 ERP/PIM/支付/物流等同步，不把业务锁死在单一厂商 |

---

## 3. 三端产品形态

- **商城前台**：面向客户的网站（可 SSR），覆盖注册登录、商品浏览与搜索、购物车结算、询价、账户与组织中心等。
- **管理后台**：面向供应商/运营团队，按权限控制菜单与操作；支持命令面板（⌘K / Ctrl+K）快速跳转与执行动作。
- **开放接口层**：REST API（可导出 OpenAPI）、API Key、出站 Webhook；业务能力按「模块」安装或关闭，不用的能力可关掉而不必改核心代码。

---

## 4. 核心业务能力（按业务域）

### 4.1 商品与目录

- 产品、规格变体、分类、属性、素材库
- 按 **销售渠道**、语言维护展示内容
- 支持自定义字段，满足行业特有信息而不必改表结构
- 前台搜索（含全文检索能力）、商品对比、SEO（元信息、站点地图等）

### 4.2 价格、税与促销

- **价格本 / 价目表**：可按币种、目录、买家组织、销售渠道等规则决定「谁看到什么价」
- 税率解析（国家 / 商品类型 / 增值税身份等）
- 购物车级促销：折扣比例、减免金额、免运费等，并可设适用条件

### 4.3 客户、组织与账户

- **组织（Organization）** 是多租户业务边界：B2B 公司账户、B2C 个人组织均可
- 组织注册、邀请成员、角色分工、地址簿
- 客户生命周期、销售代表归属
- 登录、密码重置、双因素认证（2FA）等账户安全能力

### 4.4 采购路径：直购 + 询价 + 采购辅助

平台刻意支持 **两条并行成交路径**：

| 路径 | 适用场景 | 业务结果 |
| --- | --- | --- |
| 直购（购物车 → 结账 → 订单） | 标价清晰、可立即购买 | 生成订单并进入履约 |
| 询价 RFQ（报价请求） | 大单、不定价、需销售报价 | 草稿 → 报价 → 接受/拒绝 |
| 快速下单 | 熟客按 SKU / CSV 批量点货 | 加速复购 |
| 购物清单 | 常购组合、项目备料 | 可一键转购物车或转询价 |

### 4.5 订单、支付与信用

- 下单、订单状态流转，关联支付与配送方式
- 支付方式可配置；开源层提供银行转账、自提、**信用额度**等抽象（在线卡支付网关多为商业/扩展能力）
- **信用额度**：授信、占用与释放，适合账期客户
- 支付驱动与结算事件可扩展，便于后续接网关

### 4.6 库存、发货、退货与发票

- 库存数量、预留、到货通知
- 配送方式配置；发货单生命周期（与支付侧对称的履约记录）
- 退货 / 投诉（RMA）：提交、审核、逆向物流与结算
- 发票 / 形式发票 PDF、发票台账与编号等抽象（具体报税对接可按地区扩展）

### 4.7 内容、营销与触达

- **CMS 页面搭建**：页面、区块、模板，按渠道与语言发布
- 博客 / 内容运营、可配置巨型导航（Megamenu）
- 邮件模板与事务邮件、自有邮件营销（订阅、标签、分群、活动与自动化）
- 文档模板（对比单、发票、报价单等 PDF 版式可在后台设计）
- 商品 Feed（向购物/广告平台推送）、GA / GTM / Meta / LinkedIn 等投放与分析埋点

### 4.8 销售协同与内部协作

- **CRM 销售机会**：可配置状态流，并与订单联动
- **项目与任务**：跨组织项目阶段、管理员待办与截止日期
- 管理端全局搜索、通知、操作审计

### 4.9 平台治理与扩展

- 多 **销售渠道**、多币种、多语言
- 管理员、角色、细粒度权限；敏感操作审计；可模拟登录（impersonation）做客服排查
- 模块可安装 / 启用 / 停用：停用不等于删数据，可逆
- 导入导出（CSV）、设置中心、凭证配置（如邮件/LLM 适配器）
- ERP / PIM 连接器抽象层 + Webhook，方便与现有信息系统对接
- PWA：可安装、缓存与更新策略等渐进式体验能力

## 5. 典型业务故事（端到端）

### 故事 A：企业客户按价目表直购

1. 采购员加入公司组织并登录前台  
2. 按组织价目表看到专属价格，搜索或快速下单加入购物车  
3. 选择配送与支付方式（含信用额度）完成结账  
4. 运营在后台确认订单 → 发货 → 开具发票记录  

### 故事 B：大单询价成交

1. 客户在商品页发起「询价」或从购物清单转 RFQ  
2. 销售在后台认领、报价或拒绝  
3. 客户接受报价后进入订单履约  
4. 全程可按权限查看与审计  

### 故事 C：运营上新与多渠道运营

1. 在后台维护商品、分类、渠道可见性与价格本  
2. 用 CMS / 博客 / 导航更新前台内容  
3. 配置促销、SEO、商品 Feed 与广告像素  
4. 不需要的模块在后台关闭，不影响其余业务

## 6. 开源能力边界（业务视角）

以下能力在开源平台中以 **抽象与流程** 提供，具体「对接哪家支付、哪家快递、哪国电子发票」通常通过扩展/商业模块或自研适配完成：

- 在线卡支付 / 钱包 / 本地快捷支付网关  
- 快递面单、柜机选点等承运商深度集成  
- 财务总账 / 报税通道的完整落地（如特定国家电子发票直连）  
- 特定品牌 PIM 的开箱即用同步包  

也就是说：**买卖、询价、组织、价格、订单、库存、内容与集成「骨架」齐全**；与本地支付、物流、财税厂商的「最后一公里」可按部署需要叠加。

## 7. 与本仓库业务扩展的关系（可选阅读）

本仓库在 Endora 能力之上，还可包含面向「稀缺货 / 高端硬件」的 **竞价（Bidding）** 等业务扩展：活动发布、密封回执、双人审核、转真实订单等。  

- **Endora 主体**：通用 B2B/B2C 电商与运营中台  
- **竞价扩展**：在组织、订单、库存、权限等底座上叠加的稀缺货分配场景  

若当前线上环境已启用竞价模块，对外介绍时可写为：「通用电商中台 + 竞价批采能力」；模块级细节以竞价相关产品说明为准。

---

## 8. 总结

Endora Commerce 对企业侧的价值可以概括为四点：

1. **一种系统服务两种成交方式**：标价直购与询价报价并存  
2. **以组织为中心的 B2B 运营**：成员、角色、地址、信用额度与专属价格  
3. **从获客内容到履约售后的闭环**：目录、营销、订单、库存、发货、退货、发票  
4. **可开关、可对接、可按部署扩展**：模块化启停 + API/Webhook + 连接器抽象
