# Mobii MVP 验收清单（批次 A 同步自 PRO）

对照：`PRO.md` §四门禁、一附 MVP、§六 6.2。工程细则以 `specs/165-mobii-bidding/` 为准。

## 端与角色

- [ ] 大B（Admin :3002）可登录；具备运营/销售/售后权限分工（P1 后）
- [ ] 小b（Storefront :3000）组织可注册、验证邮箱、登录
- [ ] 小c 不在 MVP

## 货品与渠道

- [ ] 大B 可上架商品到渠道 `default`
- [ ] 小b 在 `default` 上可见已发布商品

## 竞价主链（P2+）

- [ ] 大B 可发布竞价活动（产品、数量、规则、客户范围、截止、意向模板）
- [ ] 准入客户可见活动；未准入不可投（G-C1）
- [ ] 小b 可下载模板、提交意向回执（含附件 G-C3）；截止后不可投（G-C4）
- [ ] 回执绑定规则版本（G-C2）；密封至评审结束（G-C5）
- [ ] 运营 + 销售签核可追溯（G-M1/G-M2）；法务可配置
- [ ] 预付未确认不可履约放行（G-M3）；金额校验（G-M5）
- [ ] 唯一交易编号串联活动→回执→收款→订单→发货（G-M4）
- [ ] 发货满足 G-S1；售后角色发货（G-S2）；库存与配额一致（G-S3）
- [ ] 责任人可查（G-S4）；取消/落选/逾期释放库存（G-S5）

## 明确不做（MVP）

- [ ] 无公开实时升价拍卖
- [ ] 无小程序客户端
- [ ] 不以 RFQ 冒充竞价主模型
