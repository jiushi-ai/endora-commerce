### 1. 本机打镜像并推 ACR

```bash
cd ~/github/endora-commerce
git checkout feat/storefront-167-from-upstream
git rev-parse --short HEAD
# 期望：192105ff4（或你后续又提交后的新短 sha）

export IMAGE_TAG=$(git rev-parse --short HEAD)
export REGISTRY_IMAGE='mobii-b2b-registry.cn-guangzhou.cr.aliyuncs.com/mobii'
export API_PUBLIC_URL='https://api.justgoai.com'
export STOREFRONT_PUBLIC_URL='https://b2b.justgoai.com'

docker login mobii-b2b-registry.cn-guangzhou.cr.aliyuncs.com

docker build -f backend/Dockerfile -t ${REGISTRY_IMAGE}/backend:${IMAGE_TAG} .
docker build -f admin/Dockerfile --build-arg VITE_API_BASE_URL=${API_PUBLIC_URL} -t ${REGISTRY_IMAGE}/admin:${IMAGE_TAG} .
docker build -f storefront/Dockerfile \
  --build-arg NEXT_PUBLIC_API_BASE_URL=${API_PUBLIC_URL} \
  --build-arg NEXT_PUBLIC_SITE_URL=${STOREFRONT_PUBLIC_URL} \
  -t ${REGISTRY_IMAGE}/storefront:${IMAGE_TAG} .
docker push ${REGISTRY_IMAGE}/backend:${IMAGE_TAG}
docker push ${REGISTRY_IMAGE}/admin:${IMAGE_TAG}
docker push ${REGISTRY_IMAGE}/storefront:${IMAGE_TAG}

```

（若上次 lint 未修好会再挂；当前 HEAD 已含修复，应能过。）

### 2. ECS 只换 storefront

```bash
ssh aliyun-mobii
cd /opt/b2b

grep -E '^(REGISTRY_IMAGE|IMAGE_TAG)=' .env
# 记下旧 IMAGE_TAG，方便回滚

# 改成上一步的短 sha（示例）
sed -i 's/^IMAGE_TAG=.*/IMAGE_TAG=192105ff4/' .env
grep '^IMAGE_TAG=' .env

#仅启动storefront
docker compose --env-file .env -f compose.prod.yml pull storefront
docker compose --env-file .env -f compose.prod.yml up -d storefront
#总体启动 （优先选总体启动）
docker compose --env-file .env -f compose.prod.yml pull
docker compose --env-file .env -f compose.prod.yml up -d
#查看启动后进程
docker compose --env-file .env -f compose.prod.yml ps
```

不必重跑 migrate；不必动 backend/admin（除非你还要一并发别的提交）。
